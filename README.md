# Visualiseur Markdown

Un outil simple et autonome pour prévisualiser des fichiers `.md` dans le navigateur.

## Fonctionnalités
- Glisser-déposer ou sélection de fichier
- Rendu Markdown complet (titres, listes, tableaux, citations, liens, images)
- Coloration syntaxique pour les blocs de code
- Thème clair/sombre automatique selon les préférences du système
- Aucune installation requise : un seul fichier HTML, tout tourne dans le navigateur

## Utilisation
Ouvrir `visualiseur-markdown.html` dans un navigateur, puis glisser un fichier `.md` dedans.

## Technologies
- HTML/CSS/JS vanilla
- [marked.js](https://marked.js.org/) pour le parsing Markdown
- [highlight.js](https://highlightjs.org/) pour la coloration syntaxique
